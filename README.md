# APEX Karting — информационная система картодрома

Курсовой проект по теме «Проектирование и дизайн информационной системы картодрома». Технологический стек: Laravel 10.50.4, PHP 8.1+, MySQL 8, Blade, Bootstrap 5.

## Реализованные возможности

### Посетитель и клиент
- Публичная главная страница и каталог активных тарифов.
- Регистрация, авторизация и выход из учётной записи.
- Личный кабинет с историей бронирований, статусами и суммами оплат.
- Создание бронирования с выбором тарифа, даты, времени и списка участников.
- Проверка вместимости парка картов на выбранный временной интервал: учитываются длительность тарифа, число участников и пересекающиеся активные бронирования.
- Сохранение цены и длительности тарифа в бронировании, чтобы последующее изменение тарифа не меняло уже созданную заявку.

### Сотрудник
- Просмотр заявок, подтверждение и отмена бронирований.
- Создание заезда по подтверждённому бронированию.
- Автоматическое назначение свободных картов участникам.
- Запуск, завершение и отмена заезда.
- Ручной ввод времени каждого круга участника с проверкой принадлежности участника конкретному заезду.
- Управление статусом картов с запретом освобождения карты, пока связанный заезд не закрыт.

### Администратор
- Сводная статистика по бронированиям, клиентам, сотрудникам, картам и выручке.
- Просмотр и изменение данных клиентов.
- Создание учётных записей сотрудников и изменение их контактных данных/пароля.
- Просмотр и изменение статусов бронирований.
- Создание тарифов и включение/отключение их доступности.
- Добавление картов в парк и изменение их характеристик и статусов.
- Ведение журнала технического обслуживания с датой, описанием работ и стоимостью; создание записи автоматически переводит карт в статус обслуживания.
- Регистрация платежей наличными, банковской картой или онлайн-способом, учёт частичной оплаты, проверка остатка к оплате и изменение статуса платежа.
- Просмотр заездов и результатов кругов.

## Структура базы данных

В проекте используются 11 основных таблиц предметной области:

1. `roles` — роли пользователей.
2. `users` — клиенты, сотрудники и администраторы.
3. `tariffs` — тарифы и длительность заезда.
4. `bookings` — бронирования.
5. `booking_participants` — участники бронирования.
6. `payments` — платежи по бронированиям.
7. `karts` — парк картов и их текущее состояние.
8. `maintenance_records` — история технического обслуживания.
9. `race_sessions` — заезды.
10. `race_participants` — участники заездов и назначенные карты.
11. `lap_results` — результаты по кругам.

Дополнительно создаётся стандартная таблица Laravel `password_reset_tokens`.

## Установка

Требуются PHP 8.1 или новее с расширениями Laravel (включая PDO MySQL, OpenSSL, Mbstring, Tokenizer, XML, Ctype, JSON, BCMath и Fileinfo), Composer 2 и MySQL 8.

1. Распакуйте архив и перейдите в каталог `karting-system`.
2. Установите зависимости:

   ```bash
   composer install
   ```

3. Создайте `.env` и ключ приложения:

   ```bash
   cp .env.example .env
   php artisan key:generate
   ```

4. Создайте базу данных MySQL:

   ```sql
   CREATE DATABASE karting CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```
   # При использовании migrate может предложить создать таблицу сразу.

5. Укажите доступ к БД в `.env` (`DB_HOST`, `DB_PORT`, `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD`).
6. Создайте таблицы и демонстрационные записи:

   ```bash
   php artisan migrate --seed
   ```

7. Запустите приложение:

   ```bash
   php artisan serve
   ```

8. Откройте адрес, указанный Artisan (обычно `http://127.0.0.1:8000`).

## Тесты

Добавлено 13 feature-тестов на:
- разграничение доступа по ролям и изменение данных клиента;
- запрет платежей сверх остатка и некорректные переходы статусов платежей;
- запрет бронирования при превышении одновременной вместимости парка картов;
- согласованность статусов бронирования и заезда;
- завершение заезда с освобождением назначенных картов;
- запрет ручного назначения занятого статуса и освобождения карта во время активного заезда.

Запуск:

```bash
composer install
php artisan test
```

Тестовая конфигурация в `phpunit.xml` использует SQLite in-memory. Для запуска требуется установленное PHP-расширение `pdo_sqlite`.

## Границы текущей версии

- Подключение к реальному платёжному провайдеру не выполняется. Система регистрирует факт оплаты и способ оплаты, но не принимает и не хранит данные банковских карт.
- Время кругов вводится сотрудником вручную; автоматического хронометража с датчиков нет.
- Подтверждение e-mail и восстановление пароля через почту не настроены.
- Не реализованы онлайн-уведомления клиентам и интеграция с внешней кассой.
- Перед эксплуатацией необходимо добавить аудит действий, резервное копирование, политику обработки персональных данных и проверку безопасности конфигурации сервера.

## Структура проекта

- `app/Models` — модели и связи Eloquent.
- `app/Http/Controllers` — контроллеры сайта, авторизации, сотрудника и администратора.
- `app/Http/Middleware` — аутентификация и проверка ролей.
- `database/migrations` — схема БД.
- `database/seeders` — роли, демонстрационный администратор, тарифы и карты.
- `resources/views` — Blade-интерфейсы.
- `public/css/app.css` — стили интерфейса.
- `public/js/app.js` — клиентская логика формы бронирования.
- `tests/Feature` — функциональные тесты основных сценариев.
